# SMM Strategy — лендинг стратегии

Одностраничный лендинг стратегии SMM для личного бренда (RU + EN аккаунты).
Живой адрес: https://alex1986-rgb.github.io/smm-strategy/

- `index.html` — вся страница (стили и скрипты внутри файла)
- `assets/img/` — фотографии в двух размерах: полные (десктоп) и `-sm` (мобильные, ≤760 px), плюс `og.jpg` для превью в мессенджерах
- Кнопка «Печать / PDF» печатает страницу без навигации

Правки: менять только `index.html`; после пуша в `main` GitHub Actions публикует сайт автоматически.
